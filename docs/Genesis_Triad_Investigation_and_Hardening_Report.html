⚡ Pre-Dispatch Atomic Budget Reservation Mechanics

Important Definition: The $0.050 USD limit is an application-level estimated cost ceiling enforced by the Genesis Safety Governor. It is not an upstream OpenAI account billing cap. Genesis enforces pre-dispatch reservations so that concurrent or in-flight requests cannot exceed the local budget.

Step-by-Step Lifecycle:

  1. Pre-Dispatch Estimation: The orchestrator estimates turn expenditure with a 25% safety buffer before any network dispatch (~$0.000750 - $0.000950 for gpt-4o-mini).
  2. Atomic Reservation: Evaluates cumulative_spent + in_flight_reservations + new_call <= $0.050 under a thread-safe mutex. If breached, raises CostLimitExceededError before network packets leave the machine.
  3. In-Flight Protection: If Call A is in flight ($0.000850 reserved) and Call B arrives, Call B is tested against the remaining headroom after Call A's reservation.
  4. Post-Call Settlement: Releases the reserved amount and commits the exact token cost reported by the provider. If the call exceeds its estimate, the full actual amount is committed, instantly locking any subsequent reservations.
  5. Abortion Release: If an agent times out or errors, release_api_budget(res_id) frees the unspent reservation.
